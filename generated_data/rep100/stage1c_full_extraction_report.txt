Method
-------

for FOUR_FEATURES/EIGHT_FEATURES/TWENTY_FEATURES_HETEROGENEOUS in sequence
(same scoped-call pattern as the 1c-0 pilot, not the shell script — still
avoids touching ckd_fifty_features_heterogeneous's mid-migration rep
files). Writes only to each rep's own
generated_data/rep<N>/{four,eight,twenty}_features*_data.csv — no shared
state between reps.

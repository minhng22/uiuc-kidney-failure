--------------------------------------------------------------------------------
CONFIRMED 8-VARIABLE COEFFICIENTS (Tangri et al. 2011, JAMA 305(15):1553-1559)
--------------------------------------------------------------------------------

Risk score (linear predictor), same "centered-variable" form as the
4-variable model:

  L = -0.1992 * (age/10 - 7.036)
    +  0.1602 * (male   - 0.5642)
    + -0.4919 * (eGFR/5 - 7.222)
    +  0.3364 * (ln(uACR mg/g) - 5.137)
    + -0.3441 * (albumin g/dL     - 3.997)
    +  0.2604 * (phosphorus mg/dL - 3.916)
    + -0.07354* (bicarbonate mmol/L - 25.57)
    + -0.2228 * (calcium mg/dL    - 9.355)

  Risk(t) = 1 - S0(t)^exp(L)

Units (as used by both source implementations, matching standard US lab
reporting units — same convention MIMIC-IV labevents.csv reports these in):
  - age: years; male: 1, female: 0
  - eGFR: mL/min/1.73m^2 (CKD-EPI)
  - uACR: mg/g (urine albumin/creatinine ratio; itemid 51070 in this repo)
  - albumin: serum albumin, g/dL
  - phosphorus: serum phosphate, mg/dL
  - bicarbonate: mmol/L
  - calcium: serum total calcium, mg/dL

Baseline survival S0(t) (Tangri et al. 2016, JAMA 315(2):164-174 —
North-American recalibration; this repo's cohort is MIMIC-IV / US-based, so
use the "North American" column, same choice already made for the
4-variable model in EXPERIMENT_PLAN_DETAILS.md):
  - S0(2yr), North American  = 0.9780
  - S0(5yr), North American  = 0.9301
  (non-North-American values also confirmed but not needed: S0(2yr)=0.9827,
  S0(5yr)=0.9245 — only the 2-year horizon is used by this repo's KFRE
  branch per the plan.)

Note the 8-variable model's own centered mean/coefficients differ from the
4-variable model's (different coefficients: -0.1992 vs -0.2201 for age,
etc., because it's a separately-fit multivariable model, not the 4-variable
model with 4 terms appended) — this is expected and matches the published
methodology (each K-variable model is its own Cox fit).

UPDATE — DIRECT PRIMARY-SOURCE CONFIRMATION (Tangri et al. 2016, JAMA
315(2):164-174, Table 2 + Methods text, fetched directly from
jamanetwork.com/journals/jama/fullarticle/2481005)
--------------------------------------------------------------------------------
Table 2's exact caption: "Hazard Ratios for Kidney Failure of the Component
Variables in the Original vs Pooled 4- and 8-Variable Equations" — it has
TWO columns per variable:
  - "Original": the 2016 paper's own reprint, for comparison purposes, of
    the ACTUAL Tangri et al. 2011 derivation coefficients (Cox model fit on
    the 2 Canadian cohorts in the original paper).
  - "Pooled": a DIFFERENT, newly-refit set of coefficients the 2016 authors
    estimated fresh on their pooled 31-cohort multinational validation set
    ("Cox proportional hazards models were fit using the variables included
    in each of the original equations within each study, allowing both the
    regression coefficients and the baseline hazard to vary... refit
    coefficients were then pooled across studies using random-effects
    meta-analysis" — Methods). The Pooled column visibly diverges from
    Original for several variables (e.g., bicarbonate HR 0.93 -> 0.99,
    i.e. a near-null effect in the pooled refit; male sex 1.17 -> 1.34).

This repo's kfre.py uses, and this report confirms, the **Original** column
(the actual 2011 Tangri coefficients), not the Pooled refit — matching the
field convention (every clinical KFRE calculator/package deploys the
original 2011 betas, only recalibrating the S0 intercept by region, not the
2016 pooled refit):

  Variable              Original HR (Table 2)    ln(HR)     beta used above
  Age, per 10y older         0.82 [0.77-0.88]     -0.1985      -0.1992
  Male sex                   1.17 [0.95-1.46]      0.1570       0.1602
  eGFR, per 5 units          0.61 [0.58-0.65]     -0.4943      -0.4919
  ACR, per log increase      1.40 [1.28-1.53]      0.3365       0.3364
  Calcium, per 1 mg/dL       0.80 [0.68-0.95]     -0.2231      -0.2228
  Phosphate, per 1 mg/dL     1.30 [1.18-1.43]      0.2624       0.2604
  Bicarbonate, per 1 mEq/L   0.93 [0.90-0.96]     -0.0726      -0.07354
  Albumin, per 1 g/dL        0.71 [0.56-0.90]     -0.3425      -0.3441

  (Pooled/2016-refit column, NOT used, shown only for contrast: age 0.83,
  male 1.34, eGFR 0.66, ACR 1.42, calcium 0.85, phosphate 1.17,
  bicarbonate 0.99, albumin 0.70.)

  Reported reference/centering values (Methods text): "age, 70 years; 56%
  men; eGFR, 36 mL/min/1.73 m2; ACR, 170 mg/g; phosphate, 3.9 mg/dL;
  albumin, 4.0 g/dL; bicarbonate, 25.6 mEq/L; and calcium, 9.4 mg/dL" — these
  match the centering constants used above (7.036*10=70.36≈70, 7.222*5=36.1≈36,
  exp(5.137)=170.2≈170, 3.916≈3.9, 3.997≈4.0, 25.57≈25.6, 9.355≈9.4).

Every beta above lands within HR-rounding error (HRs are reported to only 2
decimal places, so +/-0.003-0.006 in log space is expected) of the value
independently reproduced by both open-source packages. This is no longer
corroboration-only: the coefficients are now confirmed against the primary
published table itself.

Patient," verbatim, not a third-party reimplementation.

eAppendix 2 gives THREE S0 variants per horizon per model size, not two:
  8-variable, 2-year:
    Original:                                1 - 0.9780 ^ exp(L)
    Regional Calibrated - North America:     1 - 0.9757 ^ exp(L)
    Regional Calibrated - non-North America: 1 - 0.9827 ^ exp(L)
    Pooled (2016 refit, not used):            1 - 0.9629 ^ exp(L_pooled)
  8-variable, 5-year:
    Original:                                1 - 0.9301 ^ exp(L)
    Regional Calibrated - North America:     1 - 0.9096 ^ exp(L)
    Regional Calibrated - non-North America: 1 - 0.9245 ^ exp(L)
    Pooled (2016 refit, not used):            1 - 0.8636 ^ exp(L_pooled)
  (L = the 8-coefficient linear predictor confirmed above, verbatim from the
  same eAppendix 2 table, exactly matching every number already verified
  against Table 2 in Update 1.)

kfre.py uses "Original" (0.9780 / 0.9301) for the North American case, NOT
"Regional Calibrated - North America" (0.9757 / 0.9096) — a deliberate,
correct choice: the 2011 derivation cohorts (AASK, BC CKD, CCF, CRIC,
Geisinger, ICES-KDT, MDRD, Mt Sinai BioMe, Sunnybrook, VA CKD) were
themselves North American, so "Original" already *is* the North American
baseline; "Regional Calibrated - North America" is a secondary, smaller
tweak the 2016 authors derived when refitting baseline hazard specifically
within the pooled North American subset (see eFigure 11). This matches the
field-standard convention used by every clinical KFRE calculator and by
both open-source packages previously checked.

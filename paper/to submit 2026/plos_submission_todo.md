**TODO 3 — state the two-year Brier evaluation interval clearly (2026-09-23)**
- Suggested manuscript wording, after verifying the final results: “We evaluated predictive performance using the integrated Brier score over days 1–730; lower scores indicate better performance.” This is a valid two-year evaluation scope. Avoid calling it “two-year accuracy”: IBS measures survival-probability prediction error across the interval, not classification accuracy or the Brier score only at day 730. See the [official IBS documentation](https://scikit-survival.readthedocs.io/en/stable/api/generated/sksurv.metrics.integrated_brier_score.html).
- Before comparing models, confirm the same evaluation interval and time grid, test patients, and censoring reference. The [official comparison tutorial](https://scikit-survival.readthedocs.io/en/stable/user_guide/evaluating-survival-models.html#time-dependent-brier-score) uses shared inputs for these. Do not compare a two-year IBS directly with an IBS integrated over a longer interval; report additional horizons separately.
- Distinguish the integration endpoint (730 days) from the training-follow-up cutoff used for censoring weights. The rep_1 warning `time must be smaller than largest observed time point: 3907.038194444444` concerns unsupported test follow-up, not a different Brier integration endpoint. See the [official Brier documentation](https://scikit-survival.readthedocs.io/en/stable/api/generated/sksurv.metrics.brier_score.html). Administratively censoring follow-up at a supported cutoff above 730 days does not change the 1–730-day integration interval.
- Current implementation: `pkgs/data_analysis/clinical_validity_analysis.py` calculates a shared censoring cutoff per scenario and uses a default 50-point grid over days 1–730 for the model comparison. Older training-time reports are inconsistent: `pkgs/experiments/utils.py` can return `None` after the warning, and RNNSurv can use a different integration interval. Verify the provenance and availability of the final reported scores; a warning is not a computed score.
